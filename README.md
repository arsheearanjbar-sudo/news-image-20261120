## How it works

`entry.png` (1024×1024, drawn with PIL in this session) is the entry.
`main.ts` (Node 22, standard library only) copies it to
`/output/entry.png`:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

A plain copy, so two runs write byte-identical files.
